# 跨 Seed 码字空间分析：码字中是否同时包含信道信息和 Seed（厂商）信息？

## 一、实验背景与动机

### 问题场景

考虑多厂商 CSI 反馈系统：
- **UE 端（终端）**：不同厂商使用各自的 encoder 压缩 CSI
- **BS 端（基站）**：只保留**一个固定不变的 decoder**（例如基于 seed42 训练的 decoder）

核心问题：直接用 seed1 的 encoder + seed42 的 decoder，模型完全无法工作。

### 类比分析框架

不同 seed 训练出的 encoder 可以类比为不同厂商的 UE encoder：
- 相同的训练数据（COST2100 indoor 场景）、相同的网络结构（TransNet encoder + Hybrid decoder）
- 唯一的区别是训练时的 random seed 不同
- 这导致 encoder 学到不同的权重，将相同的信道信息映射到不同的码字空间

**核心疑问**：码字中是否既包含信道信息，又包含"厂商（seed）身份信息"？BS 端 decoder 无法解码的原因是缺少信道信息，还是无法"理解"不同厂商的码字编码方式？

---

## 二、实验设置

### 数据来源

| 项目 | 说明 |
|:-----|:-----|
| 数据集 | COST2100 indoor 场景（train 100K / val 30K / test 30K） |
| 模型结构 | TransNet encoder + Hybrid decoder |
| 码字维度 | 512（输入 2×32×32=2048, 压缩率 cr=4） |
| 训练配置 | lr=2e-4, epochs=400, cosine scheduler, AdamW |
| 分析对象 | `exps/COST2100/in/seed{id}/transnet_hybrid/codewords/train_code.pt` |
| 样本数 | 每 seed 100,000 个 512 维码字向量 |

### 分析的 seed

选取 10 个代表性 seed：0, 42, 520, 796, 1024, 2026, 3407, 2718, 7161, 9856。另有 59 个 seed 的码字文件可用。

各 seed 的 matched NMSE（同 seed encoder + decoder）均在 -26.6 ~ -28.4 dB 之间，证明所有 seed 都成功学到了 CSI 压缩重建任务。

## 三、核心发现

### 发现 1：跨 seed 码字空间几乎正交

| 指标 | 数值 | 解读 |
|:-----|:----:|:-----|
| **质心余弦相似度** (centroid cosine) | **~0.00** (±0.08) | 不同 seed 码字分布的中心几乎正交 |
| **逐样本余弦相似度** (sample cosine) | **~0.00** (±0.03) | 同一样本在不同 seed 下的码字方向几乎无关 |
| **逐维度 Pearson 相关** (dim correlation) | **~0.00** (±0.10) | 同一维度在不同 seed 下的值几乎无关 |
| **子空间主角度** (top-64 principal angles) | **中位数 72°** (范围 49°~90°) | 前 64 个主成分跨越的子空间接近正交 |

```
seed42 vs seed0:    centroid_cos=-0.015, sample_cos_mean=-0.012, dim_corr_mean=-0.003
seed42 vs seed520:  centroid_cos=+0.007, sample_cos_mean=+0.005, dim_corr_mean=-0.001
seed42 vs seed3407: centroid_cos=+0.085, sample_cos_mean=+0.059, dim_corr_mean=+0.009
seed42 vs seed2026: centroid_cos=-0.041, sample_cos_mean=-0.025, dim_corr_mean=+0.000
```

**结论**：不同 seed 的 encoder 将相同的信道信息编码到了**完全不同的 512 维坐标系**中。这不是简单的缩放或平移，而是整个坐标系的旋转/反射。

---

### 发现 2：但特征值谱高度一致 → 内在信息结构相同

尽管坐标系不同，各 seed 码字的**方差分布（特征值谱）**几乎完全一致：

| 指标 | 数值 |
|:-----|:----:|
| **特征值谱余弦相似度** | **0.97 ~ 0.999** |
| **JS 散度** | **0.0008 ~ 0.017** |
| 有效秩 (effective rank) | 144 ~ 178 |
| 90% 方差所需维度 | 147 ~ 187 |
| Top 20 主成分方差占比 | 33% ~ 38% |

```
seed42 vs seed0:    JS_div=0.0016, eigs_cos=0.9973
seed42 vs seed520:  JS_div=0.0074, eigs_cos=0.9974
seed42 vs seed3407: JS_div=0.0008, eigs_cos=0.9992
seed42 vs seed2026: JS_div=0.0014, eigs_cos=0.9975
```

**结论**：不同 seed 的码字保留了**相同的信息复杂度结构**——信道信息的方差分布在各个主成分上的比例是一致的。这意味着信道信息本身被完整保留了，只是被放在了不同的坐标轴上。

---

### 发现 3：去质心后跨 seed 距离 ≈ 同 seed 样本间距离

| 距离类型 | L2 距离均值 |
|:---------|:----------:|
| 同 seed 不同样本 (seed42) | ~22.0 |
| 跨 seed 同一样本（原始） | ~36 ~ 43 |
| 跨 seed 同一样本（去质心后） | **~20.6 ~ 22.2** |

```
seed42 vs seed0:    原始距离=41.47 → 去质心=20.60 (同seed距离=21.91)
seed42 vs seed520:  原始距离=41.56 → 去质心=21.83 (同seed距离=21.91)
seed42 vs seed3407: 原始距离=36.07 → 去质心=21.56 (同seed距离=21.91)
seed42 vs seed2026: 原始距离=36.67 → 去质心=21.37 (同seed距离=21.91)
```

**去质心后，跨 seed 同一样本的距离（~21）与同 seed 不同样本的距离（~22）几乎相同。**

**结论**：seed 特异性的第一个来源是**质心偏移**（每个 seed 的码字有一个 DC 偏置）。减去各自质心后，跨 seed 码字的距离量级下降到样本间差异的水平。

---

### 发现 4：Procrustes 正交旋转可以恢复信道信息

去除质心后，再通过 **Orthogonal Procrustes 分析**寻找最优旋转矩阵 R，使得 `seed42_centered @ R ≈ seedX_centered`：

| Seed Pair | 旋转前距离 | 旋转后残差距离 | 残差/同seed距离 | Procrustes R² |
|:----------|:---------:|:-------------:|:---------------:|:-------------:|
| 42 → 0    | 20.65     | **4.49**      | 20.4%           | 0.884 |
| 42 → 520  | 21.87     | **3.83**      | 17.4%           | 0.934 |
| 42 → 1024 | 21.21     | **3.21**      | 14.6%           | 0.948 |
| 42 → 2026 | 21.42     | **2.74**      | 12.5%           | **0.964** |
| 42 → 3407 | 21.63     | **3.68**      | 16.8%           | 0.937 |

**经过质心平移 + 正交旋转后，跨 seed 码字的残差仅为同 seed 样本间差异的 12~20%**。Procrustes R² 达 0.88~0.96。

**结论**：跨 seed 码字的关系可以精确描述为：

```
code_s(i) = mu_s + R_s @ channel_info(i) + small_residual(i)
```

其中：
- `mu_s` = seed s 的质心（seed 特异性偏置）
- `R_s` = seed s 的正交旋转矩阵（seed 特异性坐标变换）
- `channel_info(i)` = 纯粹的信道相关信息（在 seed42 坐标系下）
- `small_residual(i)` = 不可约残差（主要来自样本级非线性差异）

---

### 发现 5：旋转矩阵离单位阵极远 → seed 信息 = 全局重排

| Seed | \|R - I\| | trace(R) | 对角线能量占比 |
|:-----|:--------:|:--------:|:-------------:|
| 0    | 32.02    | -0.62    | 0.20% |
| 520  | 32.02    | -0.57    | 0.19% |
| 2026 | 32.01    | -0.39    | 0.22% |
| 3407 | 32.03    | -1.01    | 0.19% |

- `|R - I| = 32`：旋转矩阵距离单位阵非常远（随机正交矩阵的理论值 ≈ 32）
- `trace(R) ≈ 0`：几乎没有任何维度被保留在原位
- 对角线能量仅占 0.2%：码字的每个维度都被完全重新分配

**类比**：就像把一幅图像的像素完全随机打乱——虽然信息量（熵）没有丢失，但对于只认识原始排列方式的 decoder 来说，这就是随机噪声。

---

### 发现 6：线性回归可以高精度跨 seed 预测码字

直接用线性模型从 seed42 码字预测 seedX 码字：

```
seed42 -> seed0:    overall R² = 0.966
seed42 -> seed520:  overall R² = 0.975
seed42 -> seed2026: overall R² = 0.992
seed42 -> seed3407: overall R² = 0.980
```

**一个 512×512 的线性变换矩阵就可以解释 96.6%~99.2% 的跨 seed 码字方差。**

这与发现 4 一致：码字中 seed 特异性的主体是线性变换（仿射变换 = 质心平移 + 旋转）。

---

### 发现 7：直接拼接为何完全失败

| 配置 | NMSE |
|:-----|:----:|
| seed42 encoder + seed42 decoder (匹配) | **-28.4 dB** |
| seed3407 encoder + seed42 decoder (直接拼接) | **+23.9 dB** |
| seed0 encoder + seed42 decoder (直接拼接) | **+29.2 dB** |

- NMSE 差异：从 -28.4 dB 跳到 +23.9 dB，差了 **52.3 dB**
- MSE 比值：约 **170,000 倍**

但跨 seed 的 L2 距离仅约为同 seed 样本间距离的 **1.6 倍**（36 vs 22）：

```
跨 seed 同一样本 L2 距离：~36
同 seed 不同样本 L2 距离：~22
比值：1.6x
```

**为什么 1.6 倍的 L2 距离差导致了 170,000 倍的 MSE 爆炸？**

原因在于 decoder 的结构：

```
code(512) → LayerNorm → Linear(512→512) → TokenProjection(512→2048) 
→ Reshape(32×64) → Transformer(2 layers, d_model=64) → CNN refine → CSI(2×32×32)
```

1. **LayerNorm + Linear** 对输入方向极度敏感——在错误的坐标系下，LN 的归一化会完全破坏信息
2. **Transformer 的 self-attention** 依赖 token 间的相对关系，坐标系错误会导致 attention pattern 完全失效
3. **CNN refine** 期望特定的特征图分布，错误的坐标变换会使其输入变成噪声
4. 整个 decoder 是在 seed42 码字分布上端到端训练的，**每一层都隐含地依赖 seed42 的坐标系**

类比：不是"说话声音小了 1.6 倍"，而是"用完全错误的语言在说话"——decoder 根本听不懂。

## 四、码字信息分解模型

基于以上发现，跨 seed 码字的生成过程可以建模为：

```
code_s(i) = mu_s + R_s · channel_info(i) + epsilon_s(i)
```

| 分量 | 含义 | 是否包含 seed 信息 | 能量占比（估计） |
|:-----|:-----|:-----------------:|:---------------:|
| `mu_s` | seed 特异性质心（DC 偏置） | ✅ 纯 seed 信息 | ~2%（但被 decoder LayerNorm 放大） |
| `R_s` | seed 特异性正交旋转矩阵 | ✅ 纯 seed 信息 | ~0%（保范变换，不改变能量） |
| `channel_info(i)` | 信道相关信息（坐标系无关） | ❌ 纯信道信息 | ~85-95% |
| `epsilon_s(i)` | 不可约残差 | 混合 | ~5-15% |

**关键洞察**：
- `R_s` 是一个 512×512 的正交矩阵，虽然它不改变向量的能量，但**完全改变了每个维度的语义**。对 decoder 来说，维度 0 原本代表"第一个 token 的功率"，经过 R_s 旋转后变成了"32 个 token 的某种混合"——decoder 无法理解。
- `mu_s` 看起来很小（约 0.01 量级），但经过 LayerNorm 时会与方差归一化相互作用，产生非线性放大。

## 五、回答核心问题

### Q: 码字中是否既包含信道信息，又包含 seed（厂商）信息？

**是的。** 码字中同时包含两种信息，但它们的关系是**乘法性**的而非加法性的：

```
码字 = 信道信息（内容） × seed 特异性的坐标系变换（形式）
```

类比：
- 信道信息 = 图像的像素内容
- seed 信息 = 像素的排列顺序（坐标映射）

同一张图（相同信道），用不同的像素排列方式存储，对不理解排列规则的人来说就是噪声。但**信息本身没有丢失**——只要能找到逆映射，就能恢复原图。

### Q: BS 端 decoder 无法解码的原因是什么？

**不是因为缺少信道信息，而是因为 decoder 被训练来理解 seed42 的坐标系。** 当输入来自 seedX encoder 时，虽然信道信息完整保留，但被放在了完全不同的坐标轴上。Decoder 的每一层（LayerNorm、Transformer attention、CNN）都隐含地依赖 seed42 的坐标约定，坐标系一旦改变，整个解码流水线就会崩溃。

这类似于：
- 你训练了一个英文阅读理解模型
- 现在输入是中文句子（信息量相同，但编码方式不同）
- 模型输出完全错误——不是信息丢失，而是编码方式不匹配

## 六、启示与后续方向

### 6.1 对 Adapter 设计的启示

当前 MLP adapter 的目标是学习 `code_s → code_42` 的映射。根据上述分析，这个映射主要由两部分组成：

1. **质心对齐**：`mu_s → mu_42`（512 维平移）
2. **坐标旋转**：`R_s^{-1}`（512×512 正交变换）

当前的残差 MLP adapter（512→2048→512）有 ~2.1M 参数，理论上足以学习这个映射（实际需要 512×512 + 512 ≈ 262K 参数用于线性变换，加上质心偏置约 1K）。但实际训练后仍有 3~7 dB 的 gap，说明：

- **MLP 的非线性部分（GELU 激活 + 2048 隐层）可能干扰了线性变换的学习**
- 或者残差连接结构不适配正交旋转的学习

### 6.2 改进方向

| 方向 | 具体做法 | 依据 |
|:-----|:---------|:-----|
| **分离式 adapter** | 先学质心校正（512 维 bias），再学线性旋转（512×512 矩阵），最后加小非线性残差 | 发现 3+4：主体是仿射变换 |
| **正交约束** | 约束 adapter 的线性部分接近正交矩阵 | 发现 4+5：R_s 是正交矩阵 |
| **Procrustes 初始化** | 用 Procrustes 分析得到的 R 和 mu 初始化 adapter | 发现 6：线性 R²=0.96+ |
| **解冻 decoder 浅层** | 同时微调 decoder 的 LayerNorm 和 semantic_projector | 发现 7：decoder 浅层对坐标系最敏感 |

### 6.3 对多厂商 CSI 系统的启示

1. **码字空间标准化是必要的**：不同厂商的 encoder 即使性能相同（NMSE 都在 -27~-28 dB），产生的码字也无法直接互换。BS 端要么需要针对每个厂商部署不同的 decoder（成本高），要么需要在码字层面做对齐。

2. **Adapter 方案可行但需改进**：当前 adapter 已经能将跨 seed NMSE 从 +25 dB 修复到 -21~-25 dB，证明 adapter 路线是正确的。剩余 gap 主要来自 adapter 架构和训练策略的限制，而非问题本身的不可解性。

3. **考虑在训练阶段就统一坐标系**：如果能让不同厂商在训练时就共享某些约束（如共享 decoder、码字正则化），可以避免后期适配的复杂性。
