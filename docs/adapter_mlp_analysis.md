# Adapter (mlp vs mlp_direct) 实验结果分析

## 概述

在 UniversalCSI 框架中，adapter 是一个插入在 encoder 输出和 decoder 输入之间的模块，用于**对齐不同 seed 训练出的编码器产生的码字空间**。典型场景是：encoder 来自 seedA 的预训练 checkpoint，decoder 来自 seed42 的预训练 checkpoint，两者都冻结，只训练 adapter。

两种 adapter 结构相同（LayerNorm → Linear(512→2048) → GELU → Linear(2048→512)），参数量约 **2.10M**（占模型总参数量 5.53M 的 38%），区别仅在于**残差连接和 W2 初始化**：

| Adapter | 结构 | W2 初始化 | 初始行为 |
|---------|------|-----------|---------|
| **mlp** (MLPAdapter) | `x + W2·GELU(W1·LN(x))` | **全零** | 恒等映射（保持原码字） |
| **mlp_direct** (MLPDirectAdapter) | `W2·GELU(W1·LN(x))` | **小随机** (std=0.01) | 随机噪声（阻断原码字） |

## 问题 1：mlp_direct 无残差 → 初始破坏信号

### 原因

```python
# mlp: 恒等初始化
nn.init.zeros_(self.mlp[2].weight)  # W2 = 0 → delta = 0 → output = x + 0 = x
# 初始输出 = 原码字，NMSE 完全保留预训练模型的性能

# mlp_direct: 随机初始化  
nn.init.normal_(self.mlp[2].weight, mean=0.0, std=0.01)
# output = W2·GELU(W1·LN(x)) — 小随机值，但与 x 无关
# 初始输出 ≈ 噪声，完全阻断原始码字信号
```

**后果**：
- 即使 encoder 和 decoder 来自同一个 checkpoint（seed42），mlp_direct 的初始 Test NMSE 也是 **+26.89 dB**（完全退化），而 mlp 保持了 **-28.03 dB**
- mlp_direct 需要花费 400 个 epoch 从零学习到 -27.73 dB，浪费了大量训练时间去恢复恒等映射
- 跨 seed 场景下两者的起点都是 +25~+30 dB，mlp 也没有优势（因为跨 seed 的码字本身就不匹配）

**结论**：mlp_direct 的设计在"同源"场景下是**有害的**，在跨 seed 场景下也**没有额外收益**。

## 问题 2：两种 adapter 最终有 3~7 dB 的残余性能差距

即使经过 400 个 epoch 训练，最佳跨 seed 结果（-24.92 dB）仍与匹配基准（-28.0 dB）相差约 **3 dB**。

### 原因分析

#### 2.1 delta_ratio 高达 3.5+，说明 adapter 在做大规模变换

mlp seed3407 训练过程中的指标：

| Epoch | delta_ratio | W1_norm | W2_norm | Test NMSE |
|:-----:|:-----------:|:-------:|:-------:|:---------:|
| 0 | 0.00 | 61.3 | 0.00 | +23.85 |
| 10 | 2.64 | 61.8 | 2.27 | -0.15 |
| 20 | 2.92 | 66.5 | 7.51 | -7.39 |
| 30 | 2.32 | 71.0 | 10.5 | -14.95 |
| ~400 | **3.55** | **75.9** | **23.2** | **-21.17** |

```text
delta_ratio = ||delta|| / ||x||
有效输出 = x + delta = x + 3.55*x ≈ 4.55*x
```

这**不是微调**——adapter 加的 delta 是原始码字的 3.5 倍。这意味着：
- 不同 seed 的码字空间差异极大，几乎正交
- 单靠**固定变换**（对所有样本用同一个 MLP）将 seedX 码字映射到 seed42 码字空间，是一个**高难度的全局配准问题**
- 3 dB 的残余差距可能来自**样本级别的非线性差异**，这是单个 2 层 MLP 无法捕捉的

#### 2.2 W1 的参数演化：所有权重同时增长

```text
W1_norm: 61.3 → 75.9 （增长 24%）
W2_norm: 0.0  → 23.2 （从零快速增长）
```

W2_norm 持续增长到 23.2（而初始为 0），说明训练过程**从未收敛稳定**——adapter 可能还在缓慢学习，但 400 个 epoch 后 NMSE 的改进速度已极慢。

#### 2.3 深层原因：问题本质是多 seed 码字空间对齐

从之前的码字空间分析我们知道：
- 不同 seed 的码字**各维度几乎零相关** (mean ~0.004)
- **质心几乎正交** (cosine ~0.03)
- **子空间主角度 ~74°**（接近正交）
- 但**特征值谱形状高度一致**（说明内在复杂度相似）

这意味着：
1. 不同 seed 的 encoder 学到了**不同特征的组合方式**（相同信息编码在完全不同的维度/方向上）
2. 一个 2 层 MLP 做 512→2048→512 的变换，理论上**可以学习任意非线性映射**
3. 但 2.1M 参数要拟合 100K 样本在 512D 空间的非平凡配准，**容量有限**
4. 更根本的：decoder 在 seed42 的码字分布上训练，即使完美的码字空间映射，也可能因**分布尾部的差异**而退化

## 问题 3：训练效率低下

| 实验 | 总时长 | 最终 NMSE | 有效 epoch |
|:----|:------:|:---------:|:----------:|
| mlp seed3407 | ~400 epoch | -21.17 dB | 前 30 epoch 达 -15dB，后 370 epoch 仅提升 6dB |
| mlp seed2026 | ~380 epoch | -24.68 dB | 前 30 epoch 达 -18dB |
| mlp_direct seed3407 | ~400 epoch | -21.46 dB | 前 30 epoch 达 -8dB |

训练曲线说明：
- 前 30 个 epoch **快速下降**（从 +25 dB 到 -15 dB）
- 后 370 个 epoch **缓慢改进**（-15 dB 到 -21 dB）
- 这意味着 adapter 在**前 10% 的迭代中完成了 70% 的工作**，之后进入长尾收敛

可能的瓶颈：
1. **学习率**固定为 2e-4，可能后期需要衰减
2. **SGD 优化**在高度非凸的码字配准问题上容易陷入平坦区域
3. **冻结的 encoder/decoder** 不能为 adapter 提供适应性的梯度信号

## 问题 4：为什么 mlp_direct 不仅没有优势，反而有害？

```
mlp 结构:    x → LN → W1(2048) → GELU → W2(512) → delta
                ↓                                         ↓
                └─────────── x + delta → decoder ─────────┘

mlp_direct:  x → LN → W1(2048) → GELU → W2(512) → out → decoder
             （x 被完全丢弃）
```

| | mlp | mlp_direct |
|:---|:---:|:---:|
| 初始信号保留 | ✅ 完美保留 | ❌ 完全破坏 |
| 同源（seed42） | -28 dB (优) | -27 dB 需从头恢复 |
| 跨 seed 上限 | -24.9 dB | -24.9 dB |
| 灵活性 | 学习 delta（残差） | 学习全映射 |
| 实际收益 | **残差让梯度更稳定** | 无任何额外优势 |

**核心发现**：对于码字适配任务，残差结构（学习 delta）始终优于直接映射。mlp_direct 没有任何场景下取得比 mlp 更好的结果。

## 总结与建议

### 根源问题

1. **mlp_direct 的初始化策略有缺陷**：在"匹配 seed"场景下主动破坏了已有的良好信号，在同源 encoder/decoder 的实验中毫无意义
2. **码字空间差异过大**：delta_ratio=3.5+ 说明 adapter 在做大规模变换，而非微调
3. **容量受限**：单个 2 层 MLP 难以完美拟合 512D 空间的非平凡非线性映射
4. **训练效率低**：大部分 epoch 花在长尾收敛上

### 改进方向

| 方向 | 描述 | 预期收益 |
|:----|:-----|:---------|
| **增加 adapter 深度** | 3~4 层 MLP，提高拟合能力 | 缩小 3 dB 残差 |
| **解冻部分 decoder** | 解冻 semantic_projector，让 decoder 的入口层适应新码字 | 更好利用 decoder 容量 |
| **多 adapter 融合** | 不同 seed 使用不同 adapter，测试时按需切换 | 专用化适配 |
| **训练策略改进** | 学习率衰减、早期 stop、warmup | 节省 50% 训练时间 |
| **消除 mlp_direct** | 放弃无残差设计，统一使用 mlp (residual) | 避免无用实验 |

### 关键数据汇总

```text
匹配 seed 基准（无 adapter）： -28.0 dB
── 同 seed + mlp 适配器：      -28.0 dB (无退化)
── 同 seed + mlp_direct：      -27.7 dB (浪费 400 epoch 恢复)

跨 seed + mlp（平均）：        -22.9 dB (比基准差 5.1 dB)
跨 seed + mlp_direct（平均）： -23.0 dB (与 mlp 无统计差异)

结论：mlp (residual) 是更优设计，mlp_direct 可废弃。
跨 seed 仍有 3~5 dB 提升空间，需要增大模型容量或改变训练策略。
```
