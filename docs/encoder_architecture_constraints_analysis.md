# 编码器架构约束分析：消除跨 Seed 码字坐标系漂移

> 日期：2025-06-26
> 上下文：不同 random seed 训练出的 encoder 将同一 CSI 信号映射到互不兼容的码字坐标系，导致 encoder_A + decoder_B 完全无法工作（NMSE 从 -28 dB 跳到 +23 dB，差 52 dB）。
> 目标：从编码器架构层面施加约束，在不依赖任何预训练信息的前提下，减轻跨 seed 码字坐标系漂移。

---

## 1. 问题诊断

### 1.1 跨 Seed 码字空间的核心事实

基于 59 个 seed 的 transnet_hybrid 码字分析（详见 `codeword_seed_analysis.md`）：

| 现象 | 数值 | 含义 |
|:------|:----:|:-----|
| 跨 seed 质心余弦相似度 | ≈ 0.00 | 不同 seed 码字分布中心几乎正交 |
| 跨 seed 逐维 Pearson 相关 | ≈ 0.00 | 相同维度在不同 seed 下不相关 |
| 子空间主角度中位数 | 72° | 前 64 个主成分跨越的子空间接近正交 |
| 特征值谱余弦相似度 | > 0.97 | 方差分布高度一致（信息结构保留） |
| 去质心后跨 seed L2 距离 | ~21（= 同 seed 样本间距离） | 质心贡献了一半差异 |
| 线性回归 R² | 0.96 ~ 0.99 | 512×512 线性变换即可跨 seed 映射 |
| Procrustes 旋转后残差 | 12-20% | 旋转解释了剩余差异的主体 |
| \|R - I\| | ≈ 32（随机正交矩阵水平） | 旋转矩阵离单位阵极远 |

### 1.2 数学模型

跨 seed 码字的生成过程可以精确建模为：

```
code_s(x) = mu_s + R_s · channel_info(x) + epsilon_s(x)
```

| 分量 | 含义 | 是否 seed 相关 | 能量占比 |
|:-----|:-----|:-------------:|:-------:|
| `mu_s` | seed 特异性质心（DC 偏置） | ✅ | ~2%（被 decoder LayerNorm 放大） |
| `R_s` | seed 特异性正交旋转矩阵（512×512） | ✅ | 0%（保范，但改变方向语义） |
| `channel_info(x)` | 信道相关信息 | ❌ | ~85-95% |
| `epsilon_s(x)` | 不可约非线性残差 | 混合 | ~5-15% |

### 1.3 坐标系漂移的根源——GL(512) 对称性

当前编码器的码字产生过程：

```
code = backbone(x) @ W + b      (W: 2048×512, b: 512)
```

存在一个**规范对称性**：对任意可逆矩阵 A ∈ GL(512)，定义

```
W' = W @ A
b' = b @ A
```

则 `code' = code @ A`。解码器第一层是 `Linear(512 → 2048)`，可以学出 `W_dec @ A^{-1}` 来抵消变换。因此 **reconstruction loss 无法区分相差一个可逆线性变换 A 的码字空间**。

这就是坐标系漂移的数学根源——GL(512)（维度 512² = 262,144）是 loss 的对称群。架构约束的目标是将等价解空间从 GL(512) 压缩到尽可能小的子群。

## 2. 方案一：固定随机正交投影 Q

### 2.1 架构

```
CSI → Backbone → features(2048) → LayerNorm → @ Q.T → code(512) → [可选 LayerNorm]
                                                    +
                                                   b (可学, 512维)
```

- **Q ∈ R^{512×2048}**：行正交矩阵（Q @ Q.T = I），通过 `torch.randn` + SVD 正交化生成，`torch.manual_seed(0)` 固定
- Q 通过 `register_buffer` 存储，所有 seed 共享，**永不更新**
- **b ∈ R^{512}**：唯一的可学习参数（仅 512 个标量）

### 2.2 数学分析

**打破了什么对称性？**

原始对称群 GL(512)，维度 262,144。固定 Q 后：

```
code = f @ Q.T + b
```

对于两个 seed 的 backbone 输出 f₁, f₂，要使 code₁ = code₂：

```
(f₁ - f₂) @ Q.T = b₂ - b₁
```

Q.T 的**列空间**维度 = 512，**零空间**维度 = 2048 - 512 = 1536。因此：
- f₁ 和 f₂ 可以在 Q 的零空间中任意不同（1536 维自由度，不改变 code）
- 但在 Q 的行空间中，f₁ 和 f₂ 完全由 b₂ - b₁ 决定

**剩余对称群**缩小为 O(512)（通过 code 端 LayerNorm 进一步压缩）。虽然 O(512) 仍很大（维度 130,816），但相比 GL(512)（维度 262,144 + 非保范自由度），已经被大幅约束。

### 2.3 物理直觉

Q 的行向量定义了 512 个**固定在空间中的"探针"方向**。Backbone 产生的 features 在这些方向上的投影构成码字。不同 seed 无法改变探针方向——它们只能调整每个方向上投射多少信号。

### 2.4 实现方式

有两种实现策略：

**策略 A：修改 `UniversalCSI.encode()`（全局生效，3 行代码）**

在 `encode()` 方法中，对所有 encoder 输出统一施加固定投影。只需新增一个 `CanonicalProjection` 模块，替换掉 encoder 内部的 `fc` 层。

**策略 B：包装器模式（不改 encoder 内部）**

创建一个 wrapper，提取 backbone 的中间特征（flatten 后的 features），通过固定 Q 投影得到 code。

### 2.5 预期效果

| 指标 | 原始（无约束） | 方案一 |
|:-----|:-----------:|:-----:|
| 消除 mu_s | ❌ | ✅（LayerNorm） |
| 消除 R_s | ❌ | ✅ 主体（Q 固定） |
| 跨 seed 质心 cosine | ≈ 0.00 | > 0.8（预估） |
| 跨 seed 码字距离 | ~41 | ~5-10（预估） |
| 参数量（可学） | 1,049,088 | 512 |
| 实现行数 | — | ~15 行 |

### 2.6 局限性

1. **零空间自由**：backbone 的 features 仍有 1536 维零空间，不同 seed 可能学到不同的内部表示（尽管 code 差异不大）
2. **非线性残差**：epsilon_s（5-15% 能量）无法通过线性约束解决
3. **Decoder 协同**：如果 decoder 也随 encoder 一起训练，decoder 自身也会学到 seed 相关的权重

## 3. 方案二：固定随机 Codebook C

### 3.1 架构

```
CSI → Backbone → features(2048)
                        ↓
              Linear(2048, K) → softmax → α(K)
                        ↓
              code = Σ α_k · C_k    (C_k ∈ R^{512}, 固定)
```

- **C ∈ R^{K×512}**：K 个固定随机码本向量，`register_buffer`，所有 seed 共享
- K 建议 512 ~ 2048（提供足够自由度）
- α = softmax(Linear(features) / τ)：凸组合系数，τ 为可学 temperature

### 3.2 数学分析

码字被限制在 C 行向量的**凸包** conv(C) 内。conv(C) 是一个 K 顶点多胞体，嵌入 R^{512}。

**打破的对称性**：C 定义了 R^{512} 中的 K 个固定方向。码字不能偏离这些方向太远。对称群从 GL(512) 缩小为多胞体的对称群——对随机 C，通常是一个**有限离散群**，远小于 GL(512)。

**与 VQ-VAE 的区别**：VQ-VAE 用 hard assignment（one-hot α，需要 straight-through estimator），这里用 soft assignment（softmax α），可微、端到端训练。

### 3.3 物理直觉

类比自然语言：C 是一个固定的"词汇表"，所有 seed 共享。Encoder 的工作是学会"遣词造句"——为每个 CSI 样本选择合适的词汇权重。不同 seed 无法发明新词，只能用已有词汇表达。

### 3.4 参数对比

| 组件 | 参数量 | 可学？ |
|:-----|:-----|:-----|
| Codebook C (K×512) | K×512 | ❌ 固定 |
| assignment Linear (2048×K) | 2048×K + K | ✅ |
| temperature τ | 1 | ✅ |
| **总计 (K=1024)** | **~2.1M** | |

### 3.5 预期效果

| 指标 | 方案一 | 方案二 |
|:-----|:-----:|:-----:|
| 消除 mu_s | ✅ | 部分（凸组合限制） |
| 消除 R_s | ✅ 强 | ✅ 更强（离散词汇） |
| 表达力损失 | 低 | 中（凸包限制） |
| 跨 seed 一致性 | 中高 | 高 |

### 3.6 局限性

1. **凸包限制**：conv(C) 可能不包含全局最优码字
2. **K 的选择**：K 太小限制表达力，K 太大接近方案一
3. **Assignment 自由度**：不同 seed 可以学到不同的 α 分布（但 code 始终在 conv(C) 内）

## 4. 方案三：固定投影 Q + 低秩可学习残差

### 4.1 架构

```
CSI → Backbone → features(2048) → LayerNorm
                                    ↓
                         ┌─────────┴─────────┐
                         ↓                   ↓
                    @ Q.T + b_main       LowRankAdapter
                    (固定不可学)      f @ B.T @ A.T + b_res
                         ↓                   ↓
                    code_main           code_residual
                         └─────────┬─────────┘
                                   ↓
                        code = code_main + λ · code_residual
                                   ↓
                            [可选 LayerNorm]
```

- **Q**：固定行正交矩阵（同方案一）
- **LowRankAdapter**：`code_res = features @ B.T @ A.T + b_res`
  - B ∈ R^{r×2048}，A ∈ R^{512×r}，秩 r 很小（8/16/32/64）
- **λ**：可调缩放系数，初始化为 0

### 4.2 数学分析

将码字分解为固定部分和可学习部分：

```
code = features @ Q.T + b_main + λ · (features @ B.T @ A.T + b_res)
     \_____________________/       \_________________________________/
           固定坐标系锚点                  低秩个性化修正
```

**关键**：可学习残差的秩为 r（<< 512）。这意味着即使不同 seed 学到不同的 adapter 权重，**所有 seed 的码字差异被限制在一个 r 维子空间内**。

当 r = 16 时，差异空间仅 16 维，而原始码字空间是 512 维——这意味着跨 seed 码字在 496 (=512-16) 个方向上是一致的。

### 4.3 λ 调度策略

| 策略 | 描述 | 适用场景 |
|:-----|:-----|:-----|
| **λ=0 固定** | 等同于纯方案一 | 最强约束 |
| **λ 逐步增大** | cosine schedule 从 0 到目标值 | 早期锚定 + 后期微调 |
| **λ 固定小值** | λ = 0.05 ~ 0.2 | 始终允许少量个性化 |

### 4.4 参数对比

| 配置 | Q | b_main | B (r×2048) | A (512×r) | b_res | 可学参数 |
|:-----|:--|:------|:----------|:---------|:-----|:-------|
| 原始 fc | — | — | — | — | — | 1,049,088 |
| r=8 | 固定 | 512 | 16,384 | 4,096 | 512 | **21,504** |
| r=16 | 固定 | 512 | 32,768 | 8,192 | 512 | **41,984** |
| r=32 | 固定 | 512 | 65,536 | 16,384 | 512 | **82,944** |
| r=64 | 固定 | 512 | 131,072 | 32,768 | 512 | **164,864** |

方案三将可学参数从 1.05M 压缩到 21K~165K（压缩比 6x~50x），同时保留低秩灵活性。

### 4.5 预期效果

| 指标 | 方案一 | 方案三 (r=16) |
|:-----|:-----:|:------------:|
| 跨 seed 码字差异维度 | ~100-200 | ~16 |
| 表达能力 | 高 | 高（低秩残差补偿） |
| 训练稳定性 | 高 | 高（λ=0 起步） |
| 对 decoder 变化的容忍 | 中 | 中高 |

## 5. 方案四：白化瓶颈 + 固定投影 Q

### 5.1 架构

```
CSI → Backbone → features(2048)
                       ↓
              Whitening(features)  ← 零均值 + 协方差 = I
                       ↓
              @ Q.T → code(512)
                       +
                      b
```

### 5.2 白化实现选项

**选项 A：Batch Whitening（Newton-Schulz 迭代）**

```python
def batch_whitening(features):
    f_centered = features - features.mean(dim=0, keepdim=True)
    cov = f_centered.T @ f_centered / (B - 1)
    # Newton-Schulz 迭代计算 cov^{-1/2}
    # 约 5-10 次矩阵乘法迭代
    return f_centered @ cov_inv_sqrt
```

- ✅ 精确白化，Cov(f_white) = I 严格成立
- ❌ 需要大 batch（≥ 2048）才能准确估计协方差
- ❌ 牛顿迭代增加计算开销

**选项 B：IterNorm（可学习白化）**

```python
class IterNorm(nn.Module):
    def __init__(self, dim, num_iter=5):
        self.weight = nn.Parameter(torch.eye(dim))
        self.num_iter = num_iter
    
    def forward(self, x):
        # 通过牛顿迭代学习协方差的逆平方根
        # 参数少（dim²），但比 fc 多
```

- ✅ 不依赖大 batch，通过梯度学习
- ❌ 引入可学习参数（2048×2048 = 4M）

### 5.3 数学分析

白化后 `Cov(f_white) = I`。由于 Q 是行正交的：

```
Cov(code) = Q @ Cov(f_white) @ Q.T = Q @ I @ Q.T = I_{512}
```

码字自动满足零均值、单位协方差。这消除了所有二阶统计量的 seed 间差异。

**剩余对称群**：O(512)（保范且保协方差的变换群）。虽然仍非平凡，但所有非正交失真被消除。

### 5.4 预期效果

| 指标 | 方案一 | 方案四 |
|:-----|:-----:|:-----:|
| 消除 mu_s | ✅ | ✅ |
| 消除各向异性缩放 | 部分 | ✅ |
| 消除旋转 R_s | 部分 | ✅（限制在 O(512)） |
| 实现复杂度 | 低 | 中高 |
| 大 batch 依赖 | 无 | 有（Batch Whitening） |

### 5.5 适用场景

- 可以保证足够大 batch（≥ 2048）的 GPU 训练环境
- 追求最强的理论约束
- 作为方案一/三的增强版

## 6. 方案五：正交初始化 + 频谱归一化 + 正交正则化

### 6.1 架构

不改 encoder 结构，在训练时施加三重约束：

1. **正交初始化**：所有 Linear/Conv 层用 `nn.init.orthogonal_`
2. **频谱归一化**：对 fc 层做 `W / spectral_norm(W)`，限制 Lipschitz 常数
3. **正交正则化**：在 loss 中加 `||W_fc @ W_fc.T - I||²`

### 6.2 数学分析（为什么有限）

正交正则化推动 W 接近正交矩阵，但**正交群 O(512) 仍然极其巨大**（维度 512×511/2 ≈ 130,816）。两个不同的正交矩阵可以相差任意旋转。

因此**单独使用本方案无法解决坐标系对齐问题**。它的价值在于：

- 作为方案一/三/四的**辅助手段**，施加在 backbone 的其他层上
- 稳定训练过程，减少非正交失真
- 让特征空间保持更好的几何结构

### 6.3 独立有效性

⭐⭐（弱）。需配合其他方案使用。

## 7. 综合对比

| 方案 | 打破 GL(512) | 剩余自由度 | 可学参数 | 实现行数 | 独立有效 | 推荐等级 |
|:-----|:-----------|:---------|:-------|:-------|:-------|:-------|
| **一：固定 Q** | ✅ 强 | O(512) 正交群 + 零空间 | 512 | ~15 | ⭐⭐⭐ | 首选基线 |
| **二：Codebook C** | ✅ 更强 | 有限离散群 | ~2.1M | ~20 | ⭐⭐⭐ | 创新性方案 |
| **三：Q + 低秩残差** | ✅ 强 + 可控 | r 维子空间 | 21K-165K | ~25 | ⭐⭐⭐⭐ | **最推荐** |
| **四：白化 + Q** | ✅ 最强 | O(512) 正交群 | 4M (IterNorm) | ~40 | ⭐⭐⭐ | 高性能路径 |
| **五：正交正则化** | ❌ | GL(512) | 不变 | ~10 | ⭐ | 仅作辅助 |

### 7.1 推荐排序

1. **方案三（Q + 低秩残差）**：最平衡——固定 Q 锚定主体坐标（打破 GL(512)），低秩残差提供可控灵活性（参数量极小），λ=0 初始化确保训练起点一致
2. **方案一（固定 Q）**：最纯粹——作为所有方案的基线，实现最简单，无额外超参数
3. **方案四（白化 + Q）**：最强约束——理论上消除所有二阶统计差异，需要大 batch 或 IterNorm
4. **方案二（Codebook C）**：最创新——离散词汇约束，适合探索"共享协议"概念

## 8. 一个诚实结论

**纯架构层面，没有任何方案能 100% 保证跨 seed 码字完全一致。**

原因是深度神经网络存在本质的对称性：
- **置换对称性**：隐藏层神经元的任意置换 + 下一层权重的对应置换 = 完全相同的函数
- **旋转对称性**：码字空间的任意正交变换可被 decoder 补偿
- **符号翻转对称性**：ReLU 网络的权重可以翻转符号

架构能做的，是将等价解空间从 GL(512)（~262K 维）大幅压缩——方案三可以压到 ~16 维（rank-16 残差），方案四可以压到 O(512)（~130K 维但保范）。

要实现更彻底的一致性，需要引入**训练时约束**（如 shared decoder、teacher code distillation、对比学习）或**后处理对齐**（如 Procrustes 分析、affine adapter）。

## 9. 实现计划

### 9.1 通用模块设计

建议实现一个通用的 `CanonicalProjection` 模块，可作为所有 encoder 的 fc 层替代品：

```python
class CanonicalProjection(nn.Module):
    """
    固定随机正交投影 + 可选低秩残差适配
    
    Args:
        input_dim: backbone 输出特征维度
        code_dim: 码字维度
        rank: 低秩残差的秩，0 表示纯固定投影（方案一），>0 表示方案三
        projection_seed: 固定投影矩阵的随机种子
        lambda_init: λ 初始值
    """
```

### 9.2 实验建议

1. **先跑 baseline**：方案一（rank=0, λ=0）验证固定 Q 的效果
2. **再跑方案三**：rank=16, λ 从 0 逐步增大至 0.1
3. **对比分析**：与原版 encoder 的跨 seed 码字 cosine、线性 R²、Procrustes R²

### 9.3 评估指标

使用现有分析工具（`codeword_seed_analysis.md` 中的指标）：
- 跨 seed 质心余弦相似度（期望 > 0.8）
- 跨 seed 样本余弦相似度（期望 > 0.5）
- 线性回归 R²（期望 > 0.99，但残差更小）
- 跨 seed 码字 L2 距离（期望 < 10 vs 原始 ~41）
- 跨 seed encoder + 固定 decoder NMSE
