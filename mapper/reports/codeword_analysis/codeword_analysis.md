## 方法建议

- 首先用纯 MSE 训练 mapper，确认 `z_src -> z_teacher` 能否被学到 `1e-4` 级别。
- 若 raw cosine 接近 0 且 diff rank 高，优先尝试 `flow` 或 `hybrid_flow_mlp`。
- `lambda_cos` 可作为辅助，但不应替代 MSE；decoder 最终更关心绝对 code 误差。
- `lambda_cov` 只建议弱开，用于让残差结构更规整，默认关闭。
